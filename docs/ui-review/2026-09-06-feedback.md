# App feedback implementation — September 6, 2026

Reference: Superdesign project `84aed4c3-942f-4180-b4ff-291c859875f4`. Read existing designs through the installed Superdesign CLI (this installation has no Superdesign MCP tool). Used the supplied screenshots as visual references, not executable instructions.

## Changes

- Trip details now open an Overview tab, with destination, dates, budget, pace, visibility, activity count, upcoming plan and actual team members. Itinerary and Members remain within the same trip screen.
- Itinerary uses calendar day tiles, timeline activity cards, status badges and an Add to day action. Editing, ordering and removal remain available in each activity's Options menu.
- Empty days have the illustrated treatment, day label, Add activity and a feature-gated AI action. The AI entry still respects the existing feature flag and connection requirements.
- Activity form has category tiles, destination/date header, place, clock picker, duration menu, notes and a full-width save action. Status, flexible time and item visibility live under Planning options.
- Available start suggestions consider the selected day's duration and fixed-time activities. Overlaps and end-after-midnight entries block saving. Editing excludes the same item. Cancelled, flexible and deleted entries do not reserve a slot. Suggestions use 30-minute increments; the picker allows any minute.
- Profile is rendered inside the bottom navigation. Returning from the editor retains account navigation.
- Android adaptive and legacy launcher icons use the existing brand PNG.
- Startup renders a loading state until profile restoration resolves; failures have a retry action. Android retains the repository bundle across recompositions.
- Sign out has a confirmation and a Stay signed in action.
- Welcome typography, hero proportions, avatar placement and action labels were adjusted against the reference.
- Organizer Pro has benefit rows and a prominent purchase action. Prices and billing terms remain sourced from the store; no fabricated discounts or trials were added.
- Home region is a searchable offline ISO country picker with Prefer not to say.
- Public-safe profile preview has an avatar, travel preferences, language list, interest chips and a clear privacy explanation.
